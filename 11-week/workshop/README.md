## Project

Attendance permite registrar asistencia universitaria mediante
códigos QR y consultar los registros de estudiantes y profesores.

## Baseline

La documentación del equipo indica que la implementación móvil
está pendiente. Este taller utiliza el starter Ionic React del
curso como base técnica para implementar las pantallas de Attendance.

La copia inicial conserva el código del starter sin modificaciones.
Las mejoras del taller se realizarán dentro de app/.

## Run locally

Desde 11-week/workshop/app:

npm ci
npm run dev

## Individual scope

El trabajo se enfocará en las pantallas confirmadas en - MY_SCREENS: Lista de sesiones del profesor; QR de una sesión.
La selección se coordinará con los compañeros para evitar repetir
pantallas.
El código del backend se conserva en 05-release del repositorio
del equipo. El frontend móvil está pendiente; para este taller
se utiliza el starter Ionic React del curso.
